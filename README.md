# FUTURE_DS_01
# Sales Performance Analysis — Data Science Internship Task

## 📌 Task
Analyze business sales data to identify revenue trends, top-selling products,
high-value categories, and regional performance.

## 📁 Files
- `sales_data.csv` — Sales transaction dataset (order date, category, product,
  region, quantity, unit price, revenue)
- `analyze_sales.py` — Analysis script (pandas + matplotlib). Prints key metrics
  to the console and saves charts to a `charts/` folder
- `dashboard.py` — Interactive dashboard built with Streamlit, with filters for
  region, category, and date range

## 🛠️ Tools Used
- Python
- pandas — data cleaning and analysis
- matplotlib — static charts
- Streamlit — interactive dashboard
